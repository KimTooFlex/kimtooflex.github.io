## Get Started

::: steps

1. **Install & Upgrade via NuGet**
   ::: tabs
    
    == tab "Package Manager Console" icon:package
    ```powershell "🔴 🟡 🟢"
    Install-Package KimTools.WinForms
    ```
   == tab "Package Manager GUI" icon:infinity
   ![vs-package-manager](/assets/images/package-manager.png) { .size-large .lightbox }
    == tab ".NET CLI" icon:square-terminal
    ```bash "🔴 🟡 🟢"
    dotnet add package KimTools.WinForms
    ```
   :::
    
2. **Pick your license tier**
   Choose .NET Framework, .NET Core, or PLUS depending on what your project targets.
   ::: button "Get KimTools License"  external:https://kimtoo.net/#pricing icon:key

3. **Drop controls onto the designer**
   KimTools controls appear in your Visual Studio Toolbox like any other WinForms control -no extra setup.
:::
