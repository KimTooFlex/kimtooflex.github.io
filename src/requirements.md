# System `Requirements`
KimTools is built for modern Windows Forms development and supports both legacy and current .NET platforms.

# Supported Development Environments

KimTools integrates directly with modern Windows Forms development workflows.

| Development Environment |                                                       |
| ------------------------ |:-----------------------------------------------------:|
| Visual Studio 2022 | ::: tag " Recommended " icon:check-circle color:green |
| Visual Studio Preview | ::: tag " Supported " icon:check-circle color:purple  |
| JetBrains Rider | ::: tag " Supported " icon:check-circle color:purple  |

::: callout tip "Recommended IDE"

For the best design-time experience, including drag-and-drop controls, designer editors, and toolbox integration, we recommend using the latest version of Visual Studio.

:::

# Hardware Requirements

The following specifications are recommended for a smooth development experience.

| Component | Minimum | Recommended |
| --------- | ------- | ----------- |
| Processor | 1 GHz | Multi-core CPU |
| Memory | 2 GB RAM | 8 GB or more |
| Storage | 500 MB available | SSD with additional workspace |
| Display | 1366 × 768 | Full HD or higher |



# Language Support

KimTools fully supports:

- C#
- Visual Basic (VB.NET)

Projects created using either language receive the same runtime capabilities and designer support.
 

# Internet Requirements

An internet connection is recommended for:

- Installing packages from NuGet
- Accessing documentation
- Downloading updates
- License activation
- Accessing templates and additional resources

Once installed, KimTools can be used offline.
 

# Additional Requirements

For the best experience, ensure that:

- NuGet Package Manager is enabled.
- The latest Windows updates are installed.
- Your project targets a supported .NET version.
- Windows Forms Designer is enabled within your IDE.
