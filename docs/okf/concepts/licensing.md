# Licensing

KimTools offers straightforward licensing with royalty-free distribution and unlimited project development.

::: button "View Pricing" https://kimtoo.net/#pricing icon:external-link

== side

![KimTools Licensing](assets/images/hero.png)

:::

::: callout info "Simple Developer Licensing"

KimTools is licensed **per developer**, not per application.

Choose the edition that matches your development target, activate your license, and start building. Applications created with KimTools can be distributed royalty-free under the terms of your license.

:::

::: callout tip
### Note
Starting a project from scratch? [Premium Templates](/) ship with a pre-licensed, offline-activated copy of KimTools already wired in.
:::

# Commercial Usage

KimTools is suitable for:

- Commercial desktop applications
- Internal business software
- Client projects
- Enterprise systems
- Educational software
- Personal projects

Applications created using KimTools may be distributed according to the terms of your license.
